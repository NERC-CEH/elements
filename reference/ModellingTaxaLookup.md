# Modelling Taxa Lookup

A lookup between the EVA taxon names, aggregated taxon names, and taxon
codes used in the `elements` package.

## Usage

``` r
ModellingTaxaLookup
```

## Format

A data frame with 14315 rows and 3 columns, the definitions of which
are:

- taxon:

  The taxon name as present in the EVA.

- taxon_name:

  The aggregated taxon name for use in `elements`.

- taxon_code:

  The aggregated taxon code, see
  [`elements::ModelledTaxaCodes`](https://NERC-CEH.github.io/elements/reference/ModelledTaxaCodes.md).
