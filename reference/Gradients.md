# Univariate gradient intervals for each environmental variable

A named list containing univariate gradient intervals for each
environmental variable in
[`elements::VariableNames`](https://NERC-CEH.github.io/elements/reference/VariableNames.md).

## Usage

``` r
Gradients
```

## Format

A named list with `length(elements::Gradients)` items.

- L:

  Light - 0:10

- M:

  Soil Moisture - 0:10

- N:

  Soil Nitrogen - 0:10

- R:

  Reaction - 0:10

- S:

  Salinity - 0:10

- SD:

  Soil Disturbance - 0:1

- GP:

  Grazing Pressure - 0:1

- tmax_sm:

  Maximum temperature in the warmest month - -5:55

- tmin_wt:

  Minimum temperature in the coldest month - -30:15

- prec_wt:

  Precipitation in the wettest quarter - 0:1700

- prec_sm:

  Precipitation in the driest quarter - 0:800
