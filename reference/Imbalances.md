# Presence-Absence Imbalances

The number of presences and absences in the EVA, suitable samples within
the EVA, and the training and test data, along with the presence-absence
and absence-presence imbalance ratios.

## Usage

``` r
Imbalances
```

## Format

A data frame with 28683 rows and 6 columns, the definitions of which
are:

- Stage:

  The plot selection 'stage'.

- Absent:

  The number of absences.

- Present:

  The number or presences.

- PA_Imbalance:

  The presence-absence imbalance ratio.

- AP_Imbalance:

  The absence-presence imbalance ratio.

- taxon_code:

  The taxon, see
  [`elements::ModelledTaxaCodes`](https://NERC-CEH.github.io/elements/reference/ModelledTaxaCodes.md).
