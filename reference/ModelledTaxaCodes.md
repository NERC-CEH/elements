# Taxon codes for taxa with models

Taxon codes for taxa which were successfully modelled as present in the
taxon_code column of
[`elements::ModellingTaxaLookup`](https://NERC-CEH.github.io/elements/reference/ModellingTaxaLookup.md).

## Usage

``` r
ModelledTaxaCodes
```

## Format

A vector containing 8897 strings.

## Details

`ModelledTaxaCodes`
