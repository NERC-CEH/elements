# Model variables codes

A vector containing the environmental variable codes for the model
variables; equivalent to the variable_code values in the
[`elements::VariableNamesLookup`](https://NERC-CEH.github.io/elements/reference/VariableNamesLookup.md)
data frame for rows where model_var is TRUE.

## Usage

``` r
VariableNames
```

## Format

A vector containing strings.

## Details

`VariableNames`
